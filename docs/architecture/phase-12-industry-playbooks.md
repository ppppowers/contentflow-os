# Phase 12 — Industry Playbook System

Agency-level reference playbooks per industry, generated by Claude and consulted
by the Strategy Engine when a client's industry matches.

## Coverage

11 industries: Nonprofits, Churches, HVAC, Plumbing, Electrical, Auto Repair,
Contractors, Landscaping, Law Firms, Medical Offices, SaaS (`INDUSTRIES`).

Each playbook (`playbookSchema`, strict): `campaignIdeas[]`, `topicLibrary[]`,
`seasonalContent[{when, idea}]`, `subjectLines[]`, `ctas[]`.

## Storage / flow

`industry_playbooks` (migration `0023`): agency-scoped, latest row per industry.
`/playbooks` page (new nav link) lists all 11 with a per-industry generate button
and expandable contents. `POST /api/playbooks {industry}` → `generatePlaybook`
(Claude strong) → persist.

## Strategy integration

`generatePlan` (Phase 11) now also loads `getPlaybookByIndustry(client.industry)`
(case-insensitive match) and folds the matching playbook's campaigns/topics/
seasonal ideas into the roadmap prompt — so plans inherit industry best practice.
